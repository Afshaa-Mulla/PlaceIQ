# PlaceIQ 🚀
### Campus Placement Intelligence & Analytics Platform

PlaceIQ is an end-to-end placement intelligence and career analytics platform designed for university cohorts and placement cells. It leverages machine learning to predict student readiness, simulate what-if career scenarios, map company and role fit, and provide deep insights into batch metrics.

---

## 🌟 Key Features

* **Executive Overview Dashboard:** Real-time analytics on placement rates, CTC benchmarks, and student distributions.
* **Batch & Branch Analytics:** Deep dive into department-wise performance metrics and historical placement trends.
* **Student 360° Readiness:** Comprehensive candidate profiles including academic history, skills, and projects.
* **Live What-If Predictor:** Interactive machine learning simulator to test how skill improvements affect placement probability and package offers.
* **Company & Role Fit Matcher:** Algorithmic matching of students to target industry roles based on criteria.
* **Skill Gap Center:** Identifies deficits and outlines recommended learning pathways.
* **Gemini AI Career Copilot:** AI-powered assistant for personalized career and placement guidance.
* **Excel Export Center:** Instant generation and download of comprehensive placement reports.

---

## 🛠️ Tech Stack

* **Backend:** FastAPI, Python, Uvicorn
* **Machine Learning:** Scikit-Learn, Pandas, NumPy
* **Frontend & Styling:** HTML5, Jinja2 Templates, Custom Glassmorphic Dark UI / CSS
* **AI Integration:** Google Gemini API
